## How I Develop

I focus on building software that is:

| Principle | What it means |
|---|---|
| **Practical** | Solving an actual problem rather than building for the sake of building |
| **User-focused** | Considering how people will actually use the system |
| **Maintainable** | Keeping code and database structures organized |
| **Secure** | Considering authentication, authorization, validation, and responsible data handling |
| **Continuously improving** | Learning from feedback, testing, and mistakes |

My usual development process:

<div align="center">

**Understand → Plan → Build → Test → Improve → Deploy**

</div>

I also use AI tools as development assistants for brainstorming, planning, debugging, learning, and reviewing ideas — while staying fully involved in understanding and validating the resulting code.
